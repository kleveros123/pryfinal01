Lista de Comandos Usados en Git

Comandos Básicos de Navegación

  • pwd: Muestra el directorio actual.
  • cd [ruta]: Cambia al directorio especificado.
  • ls: Lista los archivos y directorios del directorio actual.

Comandos para Manipulación de Archivos

  • touch [archivo]: Crea un archivo vacío.
  • echo "texto" > [archivo]: Escribe texto en un archivo (sobrescribe).
  • echo "texto" >> [archivo]: Añade texto al final de un archivo.
  • cp [origen] [destino]: Copia un archivo.
  • mv [origen] [destino]: Mueve o renombra un archivo.
  • rm [archivo]: Elimina un archivo.
  • mkdir [directorio]: Crea un nuevo directorio.
  • rmdir [directorio]: Elimina un directorio vacío.
  • rm -rf [directorio]: Elimina un directorio y su contenido.

Comandos de Git

  • git init: Inicializa un repositorio Git en el directorio actual.
  • git status: Muestra el estado actual del repositorio.
  • git add [archivo]: Añade un archivo al área de preparación.
  • git add .: Añade todos los archivos al área de preparación.
  • git commit -m "mensaje": Crea un commit con un mensaje descriptivo.
  • git branch [nombre]: Crea una nueva rama.
  • git switch [rama]: Cambia a la rama especificada.
  • git log: Muestra el historial de commits.
  • git clone [url]: Clona un repositorio remoto.
  • git push -u origin [rama]: Sube los cambios de la rama local al repositorio remoto.
  • git config --global user.name "Nombre": Configura el nombre de usuario global para Git.
  • git config --global user.email "correo@example.com": Configura el correo electrónico global para Git.

Otros Comandos Útiles

  • code .: Abre el directorio actual en Visual Studio Code.
  • cat [archivo]: Muestra el contenido de un archivo en la terminal.
